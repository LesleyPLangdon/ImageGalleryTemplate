Image Gallery Project

Project Description

My project is an interactive image gallery that allows users to view a collection of images and open them in a lightbox for a larger view. The gallery displays images in a neat grid format, keeping them square for a uniform look. When a user clicks on an image, it opens in a lightbox, where they can navigate through the images using arrow buttons or the keyboard. The purpose of this project is to practice working with HTML, CSS, and JavaScript while learning how to create an engaging and user-friendly web experience.

Development Process Overview

Technologies Used

  • HTML: Structured the webpage, including the gallery layout and lightbox.
  • CSS: Styled the gallery and lightbox, ensuring images display neatly and maintain a user-friendly design.
  • JavaScript: Added interactivity, including opening the lightbox, navigating images, and closing the lightbox when clicking outside or pressing the Escape key.

Challenges Faced & How I Overcame Them

  • Lightbox Not Opening: Initially, the lightbox didn’t display because of a JavaScript error. I fixed this by debugging my code and correcting a typo where I mistakenly referenced an undefined variable.
  • Maintaining Image Aspect Ratios: The gallery images needed to be square, but they had to retain their original aspect ratio in the lightbox. I solved this by using object-fit: cover; for the gallery and object-fit: contain; for the lightbox.
  • Handling Click Events Properly: There was a redundant event listener that interfered with closing the lightbox. I streamlined the code to ensure the lightbox closed only when clicking outside the image.

Features Added to Improve the Project

  • Keyboard Navigation: Users can navigate through images using the left and right arrow keys.
  • Hover Effects on Images: A hover effect enlarges images slightly when the user hovers over them, making the interface more interactive.
  • Smooth Lightbox Transition: Added CSS transitions to make the lightbox fade in and out smoothly for a better user experience.
